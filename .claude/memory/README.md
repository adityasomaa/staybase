# Carried memory

These files travel with the repo so a session started against
`adityasomaa/staybase` — from mobile, or from any fresh machine — inherits what
earlier sessions learned instead of starting cold.

`MEMORY.md` is the index. Each other file holds one durable fact: a preference,
an identifier, or a working agreement. They are the *portable* half of the
context; the *technical* half lives in `CLAUDE.md` at the repo root, which is
the file to read first.

Nothing here is loaded automatically when the project is opened from GitHub —
it is documentation, not configuration. Read `CLAUDE.md`, then skim
`MEMORY.md` if a decision looks arbitrary.
